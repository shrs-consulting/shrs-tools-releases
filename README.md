# SHRS Tools

Fertige Programme für die SHRS Desktop-App (Marketing › Tools): Video, Foto, Vektor, Light und Effekte für den Mac.
Dieses Lager enthält keinen Quellcode, nur die signierten und von Apple beglaubigten Programme. Installiert und
aktualisiert werden sie aus der SHRS Desktop-App heraus; `catalog.json` nennt je Programm den aktuellen Stand.

Die Programme sind freie Software (MIT oder Apache 2.0). Lizenztexte und Urhebervermerke liegen in jedem
Programmpaket unter `Contents/Resources/Licenses`.
